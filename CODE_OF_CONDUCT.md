# Code of conduct

## The short version

Be decent. Argue about the measurement, not the person making it.

## Expected behaviour

- Assume good faith. Someone questioning a number is doing us a favour.
- Criticise ideas, methods and code — never people.
- Accept that "you're right, we were wrong" is a normal outcome here. This
  project publishes its own limitations; that only works if being corrected
  is comfortable.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory language, or sustained
disruption. Also: bad-faith argument intended to wear people down rather
than reach the truth.

## Enforcement

Report concerns to **conduct@webxlr8.com**. Maintainers may remove
comments, close issues, or block accounts. We'll act proportionately and
keep reports confidential.
